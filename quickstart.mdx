This guide walks you from a working VitaSDK installation to actively managing packages. You will install libraries, search the repository, inspect package metadata, upgrade everything at once, and remove a package — all without touching anything outside `$VITASDK`.

## Prerequisites

Before continuing, make sure you have:

- A VitaSDK installation on disk (see [Installation](/installation) if you need one)
- The `VITASDK` environment variable set to your install path
- `$VITASDK/bin` prepended to your `PATH`

You can verify both at once:

```sh
echo $VITASDK
vdpm status
```

If `vdpm status` prints release, sequence, and toolchain information, you are ready to proceed.

<Steps>
  <Step title="Check which series is active">
    `vdpm status` shows the active release series, the channel manifest sequence number, the installed toolchain package version, and the total number of tracked packages. Run it before any session where you plan to install or upgrade packages to confirm you are on the series you expect.

    ```sh
    vdpm status
    ```

    Example output:

    ```text
    Release   2025.04
    Sequence  42
    Toolchain 2025.04-1
    Packages  1
    Installed 2025.04-1
    ```

    If the status line reads `deprecated` or `end-of-life`, vdpm will say so and point you at `vdpm channels` for current alternatives.
  </Step>

  <Step title="List available channels">
    `vdpm channels` downloads the signed channel index and prints every known release series alongside its status. Statuses include `supported`, `deprecated`, and `end-of-life`.

    ```sh
    vdpm channels
    ```

    To switch to a different series, pass its name to `vdpm refresh`:

    ```sh
    vdpm refresh nightly
    ```

    <Note>
      `vdpm refresh` requires a series name — it has no default. Run `vdpm channels` first if you are unsure what series names are available.
    </Note>
  </Step>

  <Step title="Install packages">
    Pass one or more package names to `vdpm install`. It fetches each package from the verified databases and installs it under `$VITASDK`. Packages already at the current version are skipped automatically (use `--force` to reinstall regardless).

    ```sh
    vdpm install zlib sdl2 libpng
    ```

    You can install as many packages as you need in a single invocation:

    ```sh
    vdpm install zlib bzip2 libzip libpng libjpeg-turbo sdl2 sdl2_image openssl curl
    ```

    <Tip>
      The legacy form `vdpm PACKAGE...` (without the `install` subcommand) still works and maps directly to `vdpm install PACKAGE...`. Both forms are equivalent.
    </Tip>
  </Step>

  <Step title="Search for a package">
    `vdpm search` queries the sync databases for packages whose name or description matches the given term. The search is performed against the verified local copy of the package databases.

    ```sh
    vdpm search image
    ```

    You can pass multiple terms to narrow the results:

    ```sh
    vdpm search audio mixer
    ```
  </Step>

  <Step title="Get package information">
    `vdpm info` prints the full metadata record for a package from the sync database: version, description, dependencies, conflicts, URL, and more.

    ```sh
    vdpm info sdl2
    ```

    Pass multiple names to inspect several packages at once:

    ```sh
    vdpm info sdl2 sdl2_image sdl2_mixer
    ```
  </Step>

  <Step title="See installed files">
    `vdpm files` lists every file that a package installed into `$VITASDK`. This is useful for finding the exact header or library path to add to your build system.

    ```sh
    vdpm files sdl2
    ```

    The output is a flat list of paths relative to `$VITASDK`, for example:

    ```text
    vitasdk-sdl2 /usr/local/vitasdk/arm-vita-eabi/include/SDL2/SDL.h
    vitasdk-sdl2 /usr/local/vitasdk/arm-vita-eabi/lib/libSDL2.a
    ...
    ```
  </Step>

  <Step title="List all installed packages">
    `vdpm list` queries the local pacman database and prints every package currently installed in the SDK, along with its installed version.

    ```sh
    vdpm list
    ```

    Pass package names to query specific ones:

    ```sh
    vdpm list zlib sdl2
    ```
  </Step>

  <Step title="Upgrade all packages">
    `vdpm upgrade` with no arguments performs a full system upgrade — it checks every installed package against the current databases and upgrades any that have a newer version available.

    ```sh
    vdpm upgrade
    ```

    To upgrade only specific packages, pass their names:

    ```sh
    vdpm upgrade zlib libpng
    ```

    <Note>
      On Windows, if the upgrade would replace `vitasdk-core` (which includes `vdpm.exe` and `pacman.exe` themselves), vdpm will refuse and explain that you need to re-run the bootstrap script instead. Windows cannot overwrite a running executable mid-transaction.
    </Note>
  </Step>

  <Step title="Remove a package">
    `vdpm remove` uninstalls one or more packages and removes their files from `$VITASDK`. The pacman database is updated to reflect the removal.

    ```sh
    vdpm remove zlib
    ```

    Remove multiple packages in one command:

    ```sh
    vdpm remove zlib libpng libjpeg-turbo
    ```

    <Warning>
      vdpm does not automatically remove reverse dependencies. If other installed packages depend on what you are removing, remove them first or verify they are no longer needed.
    </Warning>
  </Step>
</Steps>
