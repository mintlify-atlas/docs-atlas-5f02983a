vdpm exposes four read-only query commands that let you explore what is available in the sync database, examine package metadata in detail, check what is already installed, and list the individual files a package has placed on disk. None of these commands perform any transaction or modify your SDK root.

## search

The `search` command queries the active sync database for packages whose name or description matches the supplied term. It is useful for discovering packages before installing them.

### Usage

```
vdpm search TERM...
```

At least one search term is required. Passing multiple terms returns packages matching all of them.

### Example

```bash
vdpm search image
```

Sample output:

```
vita/libpng 1.6.43-1
    PNG image library

vita/libjpeg-turbo 3.0.3-1
    JPEG image codec with SIMD acceleration

vita/stb 20240223-1
    Single-file public domain libraries — includes stb_image
```

## info

The `info` command prints the full metadata record for a package from the sync database. Use it to read a package's description, version, dependencies, and other fields before installing.

### Usage

```
vdpm info PACKAGE...
```

At least one package name is required. Passing multiple names prints each record in sequence.

### Example

```bash
vdpm info sdl2
```

Sample output:

```
Repository      : vita
Name            : sdl2
Version         : 2.30.6-1
Description     : A library for portable low-level access to hardware
Architecture    : arm-vita-eabi
URL             : https://www.libsdl.org
Licenses        : zlib
Depends On      : None
Download Size   : 1.23 MiB
Installed Size  : 4.56 MiB
```

## list

The `list` command queries the local pacman database to show installed packages. Called without arguments it lists every installed package; called with names it filters the output to only those packages.

### Usage

```
vdpm list [PACKAGE...]
```

### Examples

List all installed packages:

```bash
vdpm list
```

Sample output:

```
sdl2 2.30.6-1
zlib 1.3.1-1
libpng 1.6.43-1
```

Check whether specific packages are installed:

```bash
vdpm list sdl2 zlib
```

---

## files

The `files` command lists every file that a package installed into the SDK root, reading from the local pacman database. This is useful for locating headers, libraries, or other assets provided by a package.

### Usage

```
vdpm files PACKAGE...
```

At least one package name is required.

### Example

```bash
vdpm files sdl2
```

Sample output:

```
sdl2 /arm-vita-eabi/include/SDL2/SDL.h
sdl2 /arm-vita-eabi/include/SDL2/SDL_audio.h
sdl2 /arm-vita-eabi/lib/libSDL2.a
sdl2 /arm-vita-eabi/lib/libSDL2main.a
```

<Note>
  The `list` and `files` commands query the local database only — they do not
  contact the sync server and work correctly without a network connection. The
  `search` and `info` commands query the sync database, which must have been
  populated by a previous `vdpm refresh`.
</Note>
